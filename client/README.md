# Client (Expo + React Native + Web)

This folder contains a minimal Expo-based starter that targets Android, iOS and Web.

Quick start:

```bash
# install expo cli if you don't have it
npm install -g expo-cli

# from client/
npm install
npm run start       # opens expo dev tools (web/android/ios)
```

Note: To create a full app you can run `npx create-expo-app .` inside this folder and merge with this scaffold.
